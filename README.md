## ✨ Preview

A página traz:
- Hero com nome, curso e badges de stack
- Terminal interativo com efeito typewriter
- Seções de projetos / foco / aprendizado
- Design responsivo dark mode

## 🚀 Rodar localmente

```bash
# dentro da pasta do repo
python -m http.server 8000
# abra http://localhost:8000
```

Ou basta abrir `index.html` no navegador.

## 📁 Estrutura

```
landing-page/
├─ index.html      # Landing page principal
└─ README.md
```

## 🌐 Deploy com GitHub Pages

1. Repo → `Settings` → `Pages`
2. Source: `main` / `/root`
3. `index.html` vira a página inicial
