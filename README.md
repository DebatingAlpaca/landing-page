# Landing Page - João Pedro da Silva

Landing page pessoal de portfólio para João Pedro da Silva, estudante de Ciência da Computação na FECAP.

## Visão geral
Landing page estática em HTML/CSS puro com visual dark de programador, terminal animado e seções de apresentação.

## Arquivos
- `index.html` - Landing page principal

## Visualizar localmente
Abra `index.html` no navegador ou sirva com um servidor simples:
```bash
cd landing-page-repo
python -m http.server 8000
```

## Deploy / GitHub Pages
O repositório está conectado ao GitHub. Para publicar com GitHub Pages:
1. Settings → Pages
2. Source: branch `main`, pasta `/root`
3. O `index.html` será a página inicial
